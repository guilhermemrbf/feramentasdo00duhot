TELEGRAM SYNC DESKTOP 0.2.0 — 00duHot
VERSÃO DE TESTE PARA WINDOWS 10/11 64 BITS

1. Extraia o ZIP e abra TelegramSync.exe. Não é necessário instalar Python.
2. Clique em Conectar Telegram. Obtenha seu API ID e API Hash em
   https://my.telegram.org > API development tools, gratuitamente.
3. Informe API ID, API Hash e seu telefone com +55. Digite o código recebido
   pelo Telegram e, se solicitado, a senha de verificação em duas etapas.
4. Na aba de substituições, configure os links/textos e teste uma legenda.
5. Escolha origem e destino por ID, @username ou link público.
   Para canais privados, sua conta precisa participar deles.
   Você precisa administrar o destino e ter autorização para republicar a origem.
6. Escolha histórico ou histórico + novos posts. Confira os canais.
7. Crie uma tarefa, selecione-a e clique em Iniciar. Teste primeiro com
   dois canais seus e poucas mensagens.

FUNCIONAMENTO
- Não precisa de Railway, servidor pago, Supabase ou login na Lovable.
- Precisa de computador ligado, aplicativo aberto e internet.
- Fechar/suspender o computador interrompe a sincronização.
- Ao reabrir, as tarefas ficam pausadas; clique em Iniciar para retomar.
- Regras são copiadas para a tarefa na criação. Alterar a aba de regras
  só afeta tarefas futuras.
- A sessão e o API Hash são protegidos pelo Windows DPAPI para o usuário
  atual. OTP e senha 2FA não são salvos. Não compartilhe a pasta de dados.
- Dados ficam em %LOCALAPPDATA%\00duHot\TelegramSync.
- Não há telemetria ou envio para servidores do 00duHot. O aplicativo
  comunica-se com o Telegram. O botão de ajuda abre my.telegram.org.
- Para revogar o acesso, desconecte pelo aplicativo ou encerre a sessão
  em Telegram > Configurações > Dispositivos.

LIMITES
Não copia membros, tópicos, respostas, reações, visualizações ou mudanças
posteriores de edição/exclusão. Não contorna conteúdo protegido.
A formatação vira texto simples. Links ocultos são expandidos para URLs.
Suporta texto, fotos, vídeos, documentos e álbuns compatíveis. Tipos não
suportados interrompem a tarefa. Legendas acima do limite exigem revisão.

Se um envio não for confirmado, a tarefa pede conferência. Abra o destino
antes de usar Conferir envio pendente. Não autorize reenvio sem verificar:
uma decisão incorreta pode duplicar a publicação. Se um álbum chegou apenas
em parte, mantenha a tarefa parada para revisão.

O executável não possui assinatura digital comercial. O arquivo SHA256SUMS.txt
na mesma versão permite conferir a integridade do ZIP. Não desative proteções
do Windows. Este é um pré-lançamento: valide em canais de teste antes de distribuir.

NOVO: EDITAR LINKS NO PRÓPRIO CANAL — 0.2.0
1. Feche o executável antigo e abra esta versão. A conta salva é mantida.
2. Pause as sincronizações. Abra a aba Editar links no canal.
3. Clique Meus canais e escolha o canal na lista, ou digite @username/ID.
4. Confira o novo destino: https://t.me/vipacessoliberado_bot
5. Se desejar, marque remover linhas “outros grupos” e “Hentai”.
6. Clique Analisar todo o histórico. Isso não altera publicações.
7. Selecione posts para conferir texto e destinos na prévia.
8. Clique Aplicar prévia / retomar e confirme o canal, ID e quantidade.

Preserva texto dos links, formatação, fotos e vídeos. Por padrão troca
links embutidos (Ctrl+K). URLs por extenso são opcionais: o texto visível
permanece, mas o clique passa a abrir o novo destino. Menções não mudam;
posts com botões são ignorados. Todos os links elegíveis do post serão
alterados: revise os destinos anteriores na prévia.
Não apaga posts inteiros: a opção de limpeza remove apenas as linhas
citadas. Exige que sua conta possa editar mensagens do canal.
Textos e formatação originais ficam no banco local, permitindo Restaurar
textos originais. Não apague a pasta de dados se precisar desse backup.
Mudanças feitas depois da prévia são ignoradas como conflitos, inclusive
na restauração. Limites do Telegram pausam a operação até o prazo indicado.
Ao pausar/fechar, uma edição em andamento pode terminar. Retome a mesma
análise para verificar o resultado, em vez de criar outra imediatamente.
Nenhuma edição ocorre automaticamente ao abrir o programa.
