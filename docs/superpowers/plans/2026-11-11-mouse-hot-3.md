# Mouse Hot 3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Permitir baixar pelo Chrome uma publicação, uma seleção ou todas as mídias encontradas no perfil, junto com os dados visíveis do perfil.

**Architecture:** O content script resolve publicações de origem conhecida e envia mídias verificáveis ao worker MV3. A fila mantém os limites existentes e salva os arquivos no Chrome. A sobreposição mostra o estado de cada operação e dá acesso ao lote e ao JSON.

**Tech Stack:** JavaScript, Chrome MV3, esbuild, Node Test, Chrome DevTools Protocol.

**Spec:** docs/superpowers/specs/2026-11-11-mouse-hot-3.md.

## Global Constraints

- Nome Mouse Hot, versão 3.0.0, Chrome 120 ou superior.
- Downloads locais, apenas mídia autorizada, sem endpoints privados, credenciais armazenadas ou novos serviços.
- Publicações sem arquivo direto são relatadas. O limite existente é 350 itens por captura e dois downloads ativos na fila.
- Qualquer corte por tempo ou quantidade deve ser mostrado. A fila existente continua verificando bytes e reporta conclusão confirmada pelo Chrome.

## Review Focus

- O vídeo só está nos dados do Reel, e a grade só contém miniatura. Resolver pelo código exato.
- Há fotos e vídeo no mesmo carrossel. Respeitar posição, formato e deduplicação.
- O usuário troca de perfil ou cancela a coleta. Abortar antes de enfileirar no perfil errado.
- Uma publicação dá erro ou só entrega miniatura. Continuar o restante e apresentar o resultado.
- O site aplica CSP. A sobreposição e a logo precisam aparecer sem depender de estilo da página ou do painel lateral.
